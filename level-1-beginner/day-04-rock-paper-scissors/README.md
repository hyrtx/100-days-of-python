# Day 04 Project: Rock, Paper and Scissors

A command-line implementation of the classic Rock, Paper, Scissors game featuring ASCII art graphics, randomized computer moves, and robust input validation.

## Objective

Apply the concepts learned on **Day 03** of the course, including:
* **Randomization** module and concepts.
* Creating and manipulating **Python Lists** for data storage and indexing.
* Integrating ASCII art for visual feedback.

*Note: This solution also incorporates more advanced structures like functions, `while` loops, and `try/except` blocks for enhanced input error handling.*

## How to Run the Code
```bash
python main.py
```
