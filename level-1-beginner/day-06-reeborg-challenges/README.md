# Day 06: Reeborg Workd Challenges (Functions & Loops)

Completed interactive coding challenges on **Reeborg's World** using Karel the Robot to master control flow, functions, and loops.

## Objective

- **Defining and Calling Functions:** Organizing reusable blocks of instructions (e.g., custom movement patterns).
- **Code Blocks & Indentation:** Understanding Python's strict scoping and indentation rules.
- **While Loops:** Executing code repeatedly as long as a specific condition remains true (useful when the exact number of iterations is unknown).
- **Conditional Logic inside Loops:** Combining `while` statements with `if/else` checks for dynamic maze navigation.

## About the Exercises
The tasks involved guiding Karel through various grid environments, hurdling obstacles, and solving navigation mazes by abstracting repetitive logic into clean, modular functions.
