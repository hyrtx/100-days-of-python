# Day 03 Project: Treasure Island

A text-based "Choose Your Own Adventure" game where the player makes decisions at critical junctions to find the hidden treasure while avoiding traps.

## Objective

Apply the concepts learned on **Day 03** of the course, including:
* **Conditional Statements** (`if`, `elif`, `else`).
* **Logical Operators** and code blocks.
* Managing **Scope** and local/global naming.
* Handling user inputs with string methods (`.strip()`, `.lower()`).

## How to Run the Code
```bash
python main.py
```
