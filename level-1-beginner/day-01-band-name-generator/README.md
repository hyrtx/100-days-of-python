# Day 01 Project: Band Name Generator

An automatic band name generator that combines your hometown with your pet's name.

## Objective

Apply the fundamental concepts from **Day 01** of the course, including:
* The `print()`function to output data.
* The `input()`function for capturing user input.
* Declaring and using variables.
* **F-strings** for string interpolation.

## How to Run the Code
```bash
python main.py
```
