# Day 05 Project: Password Generator

A secure and randomized password generator that creates complex passwords combining letters, numbers, and symbols based on user specifications.

## Objective

Apply the core concepts from **Day 05** of the course, focusing on **Python Loops** (`for`), list iterations, and range operations.

*Note: This solution leverages Python's built-in `random.choices` and `random.shuffle` modules alongside list concatenation for a cleaner, highly optimized approach.*

## How to Run the Code
```bash
python main.py
```
