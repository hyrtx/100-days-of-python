# Day 02 Project: Tip Calculator

A command-line tip calculator that computes the total bill with tip included and splits it evenly among a group of people, formatting the final amount to two decimal places.

## Objective

Apply the concepts learned on **Day 02** of the course, including:
* Working with different **Data Types** (`int`, `float`).
* Performing **Mathematical Operations** and percentage calculations.
* Using **Type Conversion** (`int()`, `float()`).
* Formatting floating-point numbers with **f-strings** (e.g., `:.2f`).

## How to Run the Code
```bash
python main.py
```
